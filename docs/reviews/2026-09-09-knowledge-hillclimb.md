## 2026-09-10 — Approved private-source canary

Jamie approved sending the two locally reviewed source passages to the OpenAI API with a synthetic image. The canary adapter uses real authenticated GitHub requests and narrows the model-visible catalog, branch and file tree to that exact scope. The first combined run made two searches and spent 3,090 research tokens, then tried to summarize the search excerpts without calling the full-source read tool. The application held the run before curation. The trace showed successful search hits for both files, so the failure was premature model completion rather than missing source access.

Three deterministic regressions first failed, then passed after a bounded correction: when a model has discovered source IDs but tries to finish without fetched evidence, the research loop gives one explicit full-read reminder. The reminder is recorded in the private trace, consumes the existing turn/token budget, and cannot turn an ignored correction into a ready result. The correction does not grant new source access.

A second run attempted `knowledge_read` with a repository ID before any search and was held after 641 research tokens. Two more regressions now cover one corrective tool result explaining how to obtain an issued source ID, followed by successful search/read, and a repeated invalid ID that holds without attempting a source read. Invalid attempts count against the original tool budget. Ordinary access, policy and snapshot failures remain fatal.

The next combined run passed with two live GitHub blob reads, three research tool calls, 5,632 research tokens, a valid ten-item curation dialogue, and one photo decision. Curation required its existing single repair; the successful repaired response reported 3,703 tokens (not the total across both curation attempts). Source hashes matched the two approved passages, the original synthetic image was unchanged, and the reply and field notes were committed together in a private local repository with no remote. The successful research run did not need either new tool-use correction; those recovery paths are verified by the deterministic regressions rather than claimed as a live recovery rate.

The reply used grouped source citations. A mutation placing an invented ID inside a group exposed a validator gap: singleton citations were checked, but grouped IDs were skipped. A valid-group case passed while the invented-group case first failed; the parser now checks every source ID inside bracketed groups. The positive case also caught the need to scan text fields individually, so JSON array delimiters and ordinary prose such as "source-qualified" are not mistaken for citations. The actual saved live reply also passes replay through this stricter validator without another model request.

This canary establishes technical operation within the approved two-passage scope. It is not an editorial benchmark: the synthetic-image interpretation was speculative and included possible confusion between the image's location and the knowledge repository. Citation entailment, retrieval recall, source/image provenance reasoning, and usefulness still need labeled human review. Private source bodies, model replies, local source identifiers and run paths remain outside this public repository.
