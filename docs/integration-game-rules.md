# The photo integration game

Imagine two stacks of source boxes, one for each original run, and a row of
empty integration boxes labeled **01, 02, 03…**

Use duplicate prints so the original boxes stay intact. Give each photograph
an identifying number on its back. For digital copies, keep its original
filename and unchanged image bytes.

1. **Start with the deepest selections.** Take the final selection box from
   each run. These are the two sources for `01`.
2. **Count each source separately.** The smaller source count is your minimum.
   The larger source count is your maximum.
3. **Spread out and examine the photographs.** Compare their qualities,
   relationships, differences and possibilities. The same photograph appearing
   in both sources needs only one place in the integration box. Similar
   photographs remain separate choices.
4. **Choose a palette within the limits.** The integration box must contain at
   least the minimum and no more than the maximum. Every photograph must come
   from one of this round's source boxes. Prepare possibilities for downstream
   curators; leave the animation's composition to them.
5. **Carry the entire selection forward.** For `02` and every subsequent
   integration, first copy every photograph from the preceding integration box
   into the new box. None may be removed or exchanged during that round.
6. **Move outward one level and add selectively.** Use the next less deep
   source box from each original run. Count those sources to establish the new
   limits. The total integration count, including inherited photographs, must
   fit within those limits. Adding nothing is allowed when the inherited
   selection already fits.
7. **Check the box and leave a scorecard.** Confirm the count, source membership
   and preservation of every inherited photograph. Record the source boxes,
   their counts, your additions and the reasons for your choices. If the rules
   conflict, pause and agree on a revision while preserving the existing boxes.
8. **Stop after completing an integration level containing 500 or more
   photographs.** Otherwise, proceed to the next numbered box and repeat. A
   completed box may exceed 500, provided it satisfies that round's source-count
   limits. Reaching 500 while an unfinished selection is still invalid does not
   finish the game.

For example, sources containing **450 and 600** photographs allow an integration
of **450–600**. Completing that level with **520** photographs finishes the game.

If a source has no next box before the finish, pause for a source-scope decision;
do not label an unfinished game complete.
