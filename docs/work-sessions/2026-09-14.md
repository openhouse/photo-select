## Working agreements

- Preserve the existing prompt and curator behavior unless a change is explicitly requested.
- Keep authenticated GitHub access read-only and opt-in. Account credentials and private source material stay outside commits.
- Retain completed integration receipts. Changed selections belong in a new versioned sequence; file integrity and curatorial judgment are evaluated separately.
- Start real photo curation only from the user's Terminal command. Offline checks do not start a model run.
- Make a bounded improvement, run the affected regressions, and retain the change when it improves the result without weakening existing guarantees.

evaluation. The focused report binds its result to the candidate files; refresh

iterating on the integration procedure or copy verifier.
